Quick Start

Run in under two minutes.

# 1. Clone
git clone https://github.com/ahmadrrrtx/xr-foundation-model.git
cd xr-foundation-model

# 2. Install
pip install -e ".[dev]"

# 3. Info
xrfm info

# 4. Defensive security search
xrfm security search "SQL injection prevention" --top-k 3

# 5. Verify reproducibility
python scripts/verify_reproducibility.py

Python API

import xrfm
cfg = xrfm.load_config("config/tiny.yaml")
model = xrfm.XRFM(cfg)
tok = xrfm.BPETokenizer.pretrained()
out = xrfm.generate(model, "Hello world", tokenizer=tok, max_new_tokens=64)
