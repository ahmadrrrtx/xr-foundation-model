Sources and licenses

Processing

Row licenses

Apache-2.0 (18,000), CC0-1.0 (4,000), MIT (2,100). Dataset-level metadata is other; no single license covers all rows.

Tokenization

From text to pinned token shards

Native shards use the T4 32,768 vocabulary; CoderSec SFT rows carry source, license and provenance fields.

Measured quality issues

CoderSec SFT: known defects

All 24,100 rows use corrupted ChatML markers: licsystem, licuser, licassistant and irit instead of <|im_start|> and <|im_end|>. The three-role structure is present, but the serialization is not canonical ChatML.

All 2,100 code blocks are generic stubs of the form def func_<id>(x, y) returning result = x + y # placeholder, regardless of the requested task. They parse as Python but do not solve the prompts. CyberNative rows are heavily duplicated: 12,000 rows collapse to 7 unique responses.

A bounded pattern scan found no obvious emails, AWS keys, private-key headers or token-like strings. This is not a formal privacy audit. The full measurement is published as QUALITY_REPORT.json.

Reproducible correction

scripts/filter_codersec_sft.py canonicalizes ChatML, drops placeholder-only code rows and deduplicates. Applied to the published revision it produces 10,007 records. The corrected output has not been published under the original revision; any release will be separately versioned so training data provenance remains intact.
