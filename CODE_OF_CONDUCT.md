# Code of Conduct

## Our Pledge

We, as members of the XR Foundation Model community, pledge to make participation a harassment-free experience for everyone, regardless of experience level, identity, or background.

## Standards

Positive behavior:
- Use welcoming and inclusive language.
- Be respectful of differing viewpoints.
- Focus on constructive criticism.
- Maintain production-quality code standards.

Unacceptable behavior:
- Harassment, trolling, or personal attacks.
- Publishing others' private information without consent.
- Submitting copied code as original without proper attribution.

## Enforcement

Maintainers have the right and responsibility to edit, remove, or reject contributions that violate this code.
