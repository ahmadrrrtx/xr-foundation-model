# XR Foundation Model — Free HuggingFace Space Backend

Host your custom trained PyTorch XRFM model live on HuggingFace Spaces for 0$.

## How to Deploy on HuggingFace Spaces:
1. Go to [huggingface.co/new-space](https://huggingface.co/new-space).
2. Set Space Name to `xrfm-backend` (or any name).
3. Select **Docker** as Space SDK.
4. Upload all files from `deployment/huggingface_space/` or push this repository!
5. HuggingFace will give you a free live backend URL: `https://yourname-xrfm-backend.hf.space`!
